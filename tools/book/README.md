# Хоббит — иллюстрированная читалка (главы 1–10)

Статический сайт: `index.html` (оглавление) → `chapter-1.html` … `chapter-10.html`.
Открывается локально, никакого сервера/сборки не нужно. Можно положить папку на любой хостинг.

## Файлы

| Файл | Что это |
|---|---|
| `index.html`, `chapter-N.html` | сгенерированные страницы — **не править руками**, пересобираются `build.py` |
| `chapters.json` | текст глав: `[{num, title, paras:[...]}]` — источник для сборки |
| `chapters.full.json` | полный (несокращённый) текст всех глав — резерв |
| `condense.py` | сокращённые гл. 1–6 (1–3 ≈10 мин вслух, 4–6 ≈7–8 мин) + переименование Мешкинс→Бэггинс во всех главах; перезаписывает `chapters.json`. Правки сокращённого текста делать здесь |
| `ch01.txt`… | тот же текст в plain text (промежуточный) |
| `build.py` | собирает страницы; **здесь список сцен + подписи в порядке сюжета** (словарь `scenes`, ключ = номер главы − 1) |
| `scenes_4_10.py` | черновик сцен гл. 4–10 (prompt + подпись); уже влит в `gen_images.py`/`build.py`, хранится как образец |
| `gen_images.py` | промпты сцен, генерирует `img/chapter-N/<slug>.png` через OpenAI `gpt-image-1` |
| `shrink.py` | делает `img/chapter-N/<slug>.jpg` 1152×768 q85 из png (страницы используют jpg) |
| `img/` | `chapter-N/*.png` оригиналы 1536×1024, `*.jpg` для страниц |

## Как добавить главу — пошагово

1. **Текст.** Источник: `https://lyoshick.narod.ru/Texts/Tolk/HobbitNN.html` (NN = 04, 05…; там же лежат
   все главы, перевод не Рахмановой, но полный). Скачать `curl -sL … -o raw_NN.html`, вычистить HTML
   в plain text (скрипт-однострочник — см. историю: strip `<script>/<style>`, `<br>`→`\n`, `</p>`→`\n\n`,
   `html.unescape`), сохранить `chNN.txt`, добавить в `chapters.json` (первые строки «Глава N» отбросить,
   следующая строка — заголовок).
2. **Сцены.** В `gen_images.py` в словарь `SCENES` добавить записи `"N_slug": "описание сцены" (префикс N_ = номер главы, файл ляжет в img/chapter-N/slug.png)`.
   Скрипт пропускает уже существующие png, генерирует только новые, 8 параллельно.
   Запуск: `OPENAI_API_KEY=… python3 gen_images.py` (ключ **не** хранится в файлах).
3. **Порядок и подписи.** В `build.py` в `scenes` добавить ключ `3: [("slug","Подпись"), …]` в порядке
   сюжета. Русские подписи короткие, 2–4 слова.
4. `python3 shrink.py && python3 build.py` — готово. Навигация prev/next и оглавление строятся сами.

## Плотность картинок (держать такой же)

- Целевой шаг: **одна картинка на ~1300–1600 символов текста** (гл. 2: 1337, гл. 3: 1233, гл. 1 — 1998,
  чуть реже, можно догнать). Считать: `len(текста главы) / 1400` ≈ число сцен.
- `build.py` расставляет картинки сам по **символам** (не по абзацам): цели `k*step`, картинка ставится
  перед ближайшим абзацем; абзацы длиннее 900 символов режутся по предложениям, чтобы картинка могла
  попасть внутрь. Стихи (абзацы с переносами) не режутся.
- Проверка равномерности после сборки (min/max символов между картинками не должны отличаться
  больше чем ~2×):
  ```python
  import re; h=open("chapter-1.html").read(); parts=re.split(r'<figure',h)[1:]
  print([len(re.sub(r'<[^>]+>','',re.sub(r'<template>.*?</template>','',p,flags=re.S))) for p in parts])
  ```
- Картинки чередуются left/right, ширина 58% колонки 1280px — так на экране всегда видна картинка.

## Визуальный стиль (обязательно тот же механизм)

В `gen_images.py`: `BASE` — общий префикс, `CHARS` — описания персонажей, которые подставляются
**только если ключевое слово встречается в промпте сцены** (`full_prompt()`).

> **Важный урок:** если перечислить всех персонажей в общем префиксе, модель рисует «парад героев»
> (Голлум, Беорн, гоблины и пауки в каждой сцене). Поэтому описание персонажа попадает в промпт только
> для сцен, где он упомянут. Новых героев добавлять в `CHARS` по ключевому слову, а не в `BASE`.

BASE, дословно:

> Warm, cozy children's picture-book illustration, soft watercolor and ink, gentle colors, friendly rounded
> characters, no text, no letters. Only the characters mentioned in the scene are shown. Everything friendly
> and gentle, suitable for a 4-year-old.

Персонажи (`CHARS`): Bilbo — curly-haired hobbit, big bare hairy feet, green waistcoat, brass buttons;
Gandalf — tall, long grey beard, pointed blue hat, grey cloak, staff; dwarves — short, round, long beards,
colorful hoods; Thorin — sky-blue hood, silver tassel; Gollum — small pale thin creature, big round pale glowing
eyes; goblins — small green-grey comical; spiders — round cartoonish big eyes; Beorn — huge man, thick black
hair and beard; elves — slender, green/brown, leaf crowns; eagles — huge golden-brown noble; wolves/trolls — big,
silly, not scary.

Параметры: `model gpt-image-1`, `size 1536x1024`, `quality medium`, n=1.

> **Стоимость (реальная):** medium ≈ $0.06–0.07/картинка, low ≈ $0.02. 150 картинок medium ≈ $10.
> Перед большим батчем — проверить лимит на аккаунте. При 429 скрипт ждёт и повторяет (до 6 раз),
> но если 429 идёт подряд — это кончились кредиты, а не rate limit: остановить и не жечь попытки.
> 4 потока, ~150 картинок ≈ 15 мин.

**Состояние на 2026-08-28:** главы 1–6 — картинки готовы; главы 7–10 — 80 сцен не сгенерированы
(кончились кредиты), на страницах SVG-заглушки. Догенерировать: `OPENAI_API_KEY=… python3 gen_images.py
&& python3 shrink.py && python3 build.py` (скрипт пропускает готовые файлы). Для экономии можно поставить
`"quality": "low"` в `gen_images.py` — ~$2 за оставшиеся 80.

Как персонажи выглядят на готовых картинках: Бильбо — рыжевато-каштановые кудри, зелёная жилетка, белая
рубашка, коричневые бриджи, босые ступни. Гэндальф — серо-синяя шляпа, серый плащ, белая борода. Гномы —
разноцветные капюшоны. Палитра тёплая акварельная; ночные сцены тёмно-синие с тёплым светом.

Проверка после генерации: собрать контрольный лист из 4–6 случайных jpg (PIL) и посмотреть — нет ли
лишних персонажей, страшных лиц, текста.

Сцены следующих глав (подсказка): гл. 11 — у Горы, потайная дверь, дрозд, последний луч солнца;
гл. 12 — Бильбо в туннеле, Смауг на золоте (дракон — большой, красно-золотой, но «не страшный»), чаша, разговор
с драконом; гл. 13 — гномы в зале, Аркенстон; гл. 14 — Смауг над Эсгаротом, Бард и чёрная стрела.
